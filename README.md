# Bank Transactions

Консольное приложение на Python для анализа банковских операций. Проект позволяет обрабатывать финансовые транзакции, формировать информацию о доходах и расходах, получать данные о курсах валют и стоимости акций, а также создавать отчёты.

## Возможности

- Загрузка банковских операций из Excel-файла.
- Обработка дат и фильтрация транзакций.
- Расчёт доходов и расходов за выбранный период.
- Группировка операций по категориям.
- Формирование сводной информации по финансовым операциям.
- Получение курсов валют через внешний API.
- Получение котировок акций через внешний API.
- Расчёт потенциальных накоплений с помощью округления расходов.
- Поиск транзакций по заданным условиям.
- Формирование отчётов по расходам, в том числе средних трат по дням недели.
- Сохранение результатов отчётов в CSV.
- Логирование работы отдельных компонентов приложения.

## Технологии

- Python - основной язык разработки.
- Poetry - управление зависимостями и виртуальным окружением.
- pandas - обработка табличных данных.
- openpyxl - работа с Excel-файлами.
- requests - HTTP-запросы к внешним API.
- python-dotenv - загрузка переменных окружения.
- pytest - автоматическое тестирование.
- Flake8, Black, isort, mypy - проверка качества, форматирования и типизации кода.

Во время работы приложения могут создаваться дополнительные директории, например `logs/` и `reports/`, для хранения логов и сформированных отчётов.

## Установка и запуск

### 1. Клонирование репозитория

```
git clone https://github.com/nastiikkk/bank_transactions.git
cd bank_transactions
```

### 2. Установка зависимостей

Для установки проекта используется Poetry.

```
poetry install
```

### 3. Настройка окружения

Создайте файл `.env` на основе шаблона `.env_example` и заполните необходимые переменные окружения для внешних API.

### 4. Запуск приложения

```
poetry run python3 src.main
```

## Настройка API

Для получения данных о курсах валют и котировках акций приложение использует внешние API.

Необходимые ключи задаются в файле `.env`. Названия переменных должны совпадать с теми, которые используются в коде.

## Модули приложения

### `main.py`

Основная точка взаимодействия с приложением. Организует запуск и предоставляет пользователю доступ к доступным возможностям программы.

### `utils.py`

Содержит вспомогательные функции для работы с исходными данными, включая чтение Excel-файлов и преобразование дат.

### `views.py`

Формирует сводную информацию о банковских операциях: доходах, расходах и результатах обработки транзакций за выбранный период.

### `services.py`

Содержит дополнительные функции обработки финансовых данных, включая работу с курсами валют, котировками акций и расчётом накоплений.

### `reports.py`

Содержит функции формирования аналитических отчётов. Реализован декоратор для автоматического сохранения результатов отчётов в CSV-файлы.

### `tests/`

Содержит автоматические тесты для проверки корректности работы утилит, представлений, сервисов и отчётов.

## Тестирование

Для запуска всех тестов выполните:

```
poetry run pytest
```

Проверка стиля кода с помощью Flake8:

```
poetry run flake8 .
```

Проверка форматирования с помощью Black:

```
poetry run black .
```

Проверка порядка импортов:

```
poetry run isort .
```

Проверка аннотаций типов с помощью mypy:
